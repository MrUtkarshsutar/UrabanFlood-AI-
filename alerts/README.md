# Alerts & Notification Subsystem - UrbanFlood AI

The alerts engine dispatches actionable early warning notifications to citizens and emergency personnel.

## Subdirectories
- `notification-service/`: Dispatch gateways integrating mock adapters, web push notifications, and future SMS/Cell Broadcast handlers.
- `templates/`: Structured multi-lingual warning templates adhering to Common Alerting Protocol (CAP) standards.
