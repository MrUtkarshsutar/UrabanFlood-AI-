# Simulation Subsystem - UrbanFlood AI

The simulation module facilitates scenario stress-testing, synthetic storm modeling, and "what-if" planning for municipal authorities.

## Subdirectories
- `rainfall/`: Synthetic storm hyetographs (e.g. 50mm/hr cloudburst scenarios, 1-in-50-year rainfall curves).
- `flood-model/`: Simplified cellular automata and 1D/2D hydraulic overland flow models for urban catchments.
- `scenarios/`: Pre-configured disaster management simulations (e.g. high tide concurrent with heavy monsoon precipitation).
